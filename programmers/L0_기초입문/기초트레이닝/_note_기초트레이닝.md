### 문제 핵심

`queries`에 들어 있는 두 인덱스의 값을 순서대로 교환하는 문제이다.

```python
arr = [0, 1, 2, 3, 4]
queries = [[0, 3], [1, 2], [1, 4]]
result = [3, 4, 1, 0, 2]
```

[풀이 코드 보기](./190_수열과_구간_쿼리_3.py)

### 풀이 코드

```python
def solution(arr, queries):
    for i, j in queries:
        arr[i], arr[j] = arr[j], arr[i]

    return arr
```

### 실행 과정

| 실행 | 교환 | `arr` 결과 |
|---|---|---|
| 초기 상태 | - | `[0, 1, 2, 3, 4]` |
| `[0, 3]` | `0` ↔ `3` | `[3, 1, 2, 0, 4]` |
| `[1, 2]` | `1` ↔ `2` | `[3, 2, 1, 0, 4]` |
| `[1, 4]` | `2` ↔ `4` | `[3, 4, 1, 0, 2]` |

### 1. 특정 인덱스의 값 꺼내기

```python
arr = [10, 20, 30, 40]

value = arr[2]

print(value)  # 30
```

리스트의 인덱스는 `0`부터 시작한다.

### 2. 특정 인덱스의 값 대체하기

```python
arr = [10, 20, 30, 40]

arr[2] = 100

print(arr)  # [10, 20, 100, 40]
```

`arr[2]`의 기존 값 `30`이 `100`으로 대체된다.  
리스트의 길이는 변하지 않는다.

### 3. `insert()`를 사용하면 안 되는 이유

```python
arr = [10, 20, 30, 40]

arr.insert(2, 100)

print(arr)  # [10, 20, 100, 30, 40]
```

`insert()`는 기존 값을 대체하지 않고 새로운 값을 삽입한다.

- 기존 값은 삭제되지 않고 뒤로 밀린다.
- 리스트의 길이가 증가한다.
- 뒤에 있는 값을 이동시키므로 시간 복잡도는 `O(n)`이다.

| 목적 | 문법 | 결과 |
|---|---|---|
| 기존 값 대체 | `arr[2] = 100` | `[10, 20, 100, 40]` |
| 새로운 값 삽입 | `arr.insert(2, 100)` | `[10, 20, 100, 30, 40]` |

따라서 두 인덱스의 값을 교환할 때는 `insert()`가 아니라 인덱스 대입을 사용해야 한다.

### 4. `arr.copy()` 사용 여부

#### 원본을 직접 변경

```python
answer = arr
```

`answer`와 `arr`이 같은 리스트를 가리킨다.  
따라서 `answer`를 변경하면 `arr`도 변경된다.

#### 원본을 복사

```python
answer = arr.copy()
```

새로운 리스트를 만들기 때문에 `answer`를 변경해도 원본 `arr`은 변하지 않는다.

| 방법 | 추가 시간 | 추가 메모리 | 사용 기준 |
|---|---:|---:|---|
| `arr` 직접 변경 | 없음 | `O(1)` | 원본을 보존할 필요가 없을 때 |
| `arr.copy()` | `O(n)` | `O(n)` | 원본을 보존해야 할 때 |

이 문제에서는 원본 `arr`을 다시 사용할 필요가 없으므로 복사하지 않고 직접 변경해도 된다.

### 5. `for i, j in queries:`가 가능한 이유

```python
queries = [[0, 3], [1, 2], [1, 4]]

for i, j in queries:
    print(i, j)
```

실행 과정:

```python
i = 0, j = 3
i = 1, j = 2
i = 1, j = 4
```

`queries`의 각 요소에 값이 2개씩 있으므로 각각 `i`, `j`에 나누어 대입할 수 있다.

다음 코드와 같은 의미이다.

```python
for idx_list in queries:
    i = idx_list[0]
    j = idx_list[1]
```

리스트의 값을 여러 변수에 나누어 대입하는 것을 **언패킹(Unpacking)**이라고 한다.

### 6. 인덱스를 직접 사용하지 않는 이유

다음과 같이 작성할 수도 있다.

```python
answer[idx_list[0]] = j_val
answer[idx_list[1]] = i_val
```

하지만 `i`, `j`라는 변수명을 사용하면 코드가 더 짧고 읽기 쉽다.

```python
for i, j in queries:
```

`i`, `j`가 사용하는 추가 메모리는 `O(1)`이므로 메모리 차이는 거의 없다.

### 7. 두 값 교환하기

임시 변수를 사용하면 다음과 같다.

```python
i_val = arr[i]
j_val = arr[j]

arr[i] = j_val
arr[j] = i_val
```

파이썬에서는 다중 대입으로 줄일 수 있다.

```python
arr[i], arr[j] = arr[j], arr[i]
```

파이썬은 왼쪽에 바로 대입하지 않고, 오른쪽 값을 먼저 모두 꺼낸다.

```python
temp1 = arr[j]  # 기존 arr[j]
temp2 = arr[i]  # 기존 arr[i]

arr[i] = temp1
arr[j] = temp2
```

따라서 기존 `arr[i]` 값이 사라지기 전에 저장되므로 안전하게 교환된다.

### 8. 코딩테스트 관점

```python
def solution(arr, queries):
    for i, j in queries:
        arr[i], arr[j] = arr[j], arr[i]

    return arr
```

- 불필요한 리스트 복사가 없다.
- 임시 리스트를 생성하지 않는다.
- 언패킹을 사용해 인덱스를 간결하게 표현한다.
- 다중 대입을 사용해 두 값을 안전하게 교환한다.
- 파이썬 문법에 적합하고 가독성이 좋다.

### 복잡도

- 시간 복잡도: `O(q)`
- 추가 공간 복잡도: `O(1)`
- `q`: `queries`의 개수
